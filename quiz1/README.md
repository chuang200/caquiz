# Computer Architecture Quiz 1 Implementation

This repository contains the solutions for Quiz 1, split into three problems:

-   [Problem A: Vector API](ProblemA/README.md)
-   [Problem B: uf8 Codec](ProblemB/README.md)
-   [Problem C: BFloat16](ProblemC/README.md)

## Structure

-   `ProblemA/`: Source code and tests for the Vector API.
-   `ProblemB/`: Source code and tests for the uf8 codec.
-   `ProblemC/`: Source code and tests for BFloat16 implementation.

## Usage

Each problem folder contains a `Makefile`. You can build and run tests for each problem independently.

Example for Problem A:

```bash
cd ProblemA
make
./test
```

Example for Problem B:

```bash
cd ProblemB
make
./test
```

Example for Problem C:

```bash
cd ProblemC
make
./test
```
